# /update-brief
The user will describe the change. 1. Apply it to docs/PROJECT_BRIEF.md (or .agents/rules/02 or 03 when it affects data rules or design), keeping everything else intact. 2. Add a dated entry to docs/DECISIONS.md explaining why. 3. Adjust affected tasks in docs/DEVELOPMENT_PLAN.md. 4. List the code that must change. Do not change application code until the user confirms.
